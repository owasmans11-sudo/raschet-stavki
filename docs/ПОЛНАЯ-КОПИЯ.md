# Полная копия проекта на другом компьютере

Снимок подготовлен 18.11.2026 08:56.

Получите репозиторий командой git clone с веткой main. В копии есть исходники, рабочая база SQLite, вложения, созданные документы, факсимиле, планы, итоги и навыки.

Следуйте инструкции app-sklad/ЗАПУСК.md для установки Python. Для открытия именно перенесённых данных задайте SKLAD_DB абсолютным путём к app-sklad/sklad.db внутри клона. Задайте SKLAD_CRED_FILE путём к новому личному файлу входа. Запустите python app-sklad/server.py --no-browser из корня клона и откройте адрес сервера.

В снимке сохранены бизнес-таблицы. Данные аутентификации и активные сеансы очищены, поэтому первый запуск выдаст новый пароль andrey. Сохраните его локально. Почтовые пароли задайте через настройку почты на новом компьютере. Локальные пути в сетевых настройках и ярлыках потребуется проверить для нового ПК.

Для резервного копирования после начала работы используйте механизм SQLite Backup приложения. Репозиторий содержит состояние данных на момент снимка. Новые изменения рабочей базы потребуют нового снимка.

В поставку не входят кэши Python, временные файлы Office, журналы браузерных тестов, окружения и личные наклейки tools/scooby_gifs.
