# Маршрутизатор правил

Перед любой задачей: найди её тип в таблице и прочитай **все** указанные файлы. Не нашёл тип или правила
противоречат друг другу — спроси меня, не выдумывай своё правило.

| Тип задачи | Читать обязательно |
|---|---|
| Любая работа в репозитории (коммит, скрипт, деплой) | `safety-workflow.md` |
| Публичный текст (сайт, пост, письмо) | `{{texts/style.md}}` |
| Интерфейс и дизайн | `{{design/brand.md}}` |
| Юридические документы и обещания клиентам | `{{legal/...}}` |

## Как добавляется новое правило

Когда я говорю «не так, потому что…», запиши это в подходящий файл в формате:

```
## {{Короткое название}}
**Правило:** что делать или не делать.
**Почему:** какая ошибка или риск за этим стоит.
**Как применять:** в каких случаях и как проверить.
```

Если появился новый тип задач — добавь строку в таблицу выше.
