# План: документооборот по заявкам в «Складе ВЛ»

**Дата:** 2026-11-14  **Размер:** M  **Статус:** ждёт «да»

## Что хотим получить
Владелец: «давай сделаем документооборот исходя из заявок, чтобы я мог выгружать их».
У каждого груза (заявки) видно, какие документы по нему должны быть, какие уже есть, каких не хватает,
и всё можно выгрузить одной кнопкой — по одной заявке или пачкой (по клиенту, по периоду).

## Какие документы у груза (по цепочке из памяти проекта)
1. Договор-заявка с клиентом — приложение уже печатает.
2. Заявки перевозчикам: забор (до склада), фура (межгород), развоз (со склада) — приложение уже печатает.
3. ТН — скан, прикрепляется (подписанная, от водителя / Константина).
4. Счёт клиенту — номер уже есть в карточке («Счёт клиенту №»); файл — прикрепляется (делается в 1С).
5. УПД (или акт) — прикрепляется (делается в 1С).
6. Фото погрузки / выгрузки — прикрепляются.
7. Отправка клиенту: номер РПО Почты России и дата.

## Критерии приёмки
- [ ] В карточке груза раздел «Документы»: список из 7 пунктов, у каждого ✓ есть / ✗ нет; заявки ВЛ создаются
      кнопкой (как сейчас), остальное — «прикрепить файл» (выбор файла или Ctrl+V), можно несколько файлов.
- [ ] Поле «РПО» + дата отправки; когда заполнено — статус документов «отправлено клиенту».
- [ ] Кнопка «Скачать пакет» у груза → ZIP `<№ груза> <Клиент> <маршрут>.zip` со всеми документами, имена понятные
      («1 Заявка с клиентом.docx», «3 ТН.pdf», «5 УПД.pdf» …).
- [ ] Новая вкладка «Документы»: таблица всех грузов — клиент, маршрут, дата, отметки по каждому документу, РПО;
      фильтры: период, клиент, менеджер, «чего не хватает» (например, «нет УПД»).
- [ ] Из вкладки — выгрузка: «Excel-реестр» (кто что сдал, чего нет) и «Скачать пакеты» по отмеченным/отфильтрованным грузам
      (один ZIP, внутри папки по клиентам).
- [ ] Файлы хранятся в `app-sklad/files/gruz/<id>/` (как у водителей), не в git; резервная копия их тоже берёт.
- [ ] Проверено на копии базы: прикрепить, скачать пакет, реестр, повторная выгрузка ничего не портит.

## Не делаем
- Счёт, акт, УПД сами не формируем — их делает Анастасия в 1С, у нас только файл и номер.
- Автоматическая раскладка ТН из почты по грузам — отдельный план (2026-11-05_тн-и-документы-в-папки-перевозок.md).
- Отправка пакета клиенту по почте — только выгрузка, отправляет человек.

### Фаза 2: вкладка «Документы» и массовая выгрузка
- Что делаем: таблица с фильтрами, Excel-реестр, ZIP пачкой.
- Файлы: `app-sklad/static/app.js`, `app-sklad/dokumenty.py`, `app-sklad/excel.py`.

## Риски и края
- Большие сканы — ZIP пачкой за год может быть сотни МБ: показывать размер перед выгрузкой.
- У старых грузов (из УЛ, варианта 7) файлов нет — в реестре будут «✗», это нормально.
- После обновления приложение нужно перезапустить (закрыть чёрное окно и открыть ярлык).
