# Справочники для расчёта перевозки

Для расстояния между городами используй references/mo-distances.csv. Правила применимости и точность указаны в references/distances.md. Для груза читай references/cargo.md. Для поиска пары используй scripts/lookup.py, передав города двумя аргументами.

Фактические данные заявки имеют приоритет. Размеры транспортного места включают упаковку и палету. Масса брутто включает тару один раз. Сведения о пустой таре не определяют вес её содержимого. Для неопределённого артикула выводи предварительные сценарии с источником и допущениями. При проверке ограничения на место проверяй именно место. За коэффициентом объёма и тарифом обращайся к текущим правилам ATI пользователя.
