# Запуск Склад ВЛ на новом компьютере

Инструкция для Windows и PowerShell. Нужны Git, Python 3.12 и браузер. Microsoft Word или совместимый редактор нужен для просмотра и редактирования DOCX. Сборка JavaScript, Node.js и отдельный сервер базы не нужны.

## Получение проекта

```powershell
git clone --branch main https://github.com/owasmans11-sudo/raschet-stavki.git
Set-Location raschet-stavki
git status --short
py -3.12 --version
```

Если `py` отсутствует, установите Python с лаунчером Windows или используйте `python` с явной проверкой версии. При отказе в доступе к репозиторию используйте свою учётную запись GitHub с выданным доступом. Для обновления уже клонированного проекта запустите `git pull --ff-only` на ветке `main`, предварительно проверив `git status`.

## Первое включение с перенесёнными данными

Выполните из корня репозитория. Команды ниже указывают интерпретатор напрямую, активировать окружение не требуется.

```powershell
py -3.12 -m venv .venv
$python = Join-Path $PWD '.venv\Scripts\python.exe'
$devData = Join-Path $env:LOCALAPPDATA 'SkladVL'
New-Item -ItemType Directory -Force -Path $devData | Out-Null
$env:SKLAD_DB = Join-Path $PWD 'app-sklad\sklad.db'
if (!(Test-Path -LiteralPath $env:SKLAD_DB)) {
    throw 'Не найдена база app-sklad\sklad.db. Проверьте ветку main и полноту скачивания.'
}
$env:SKLAD_CRED_FILE = Join-Path $devData 'login.txt'
$env:SKLAD_PORT = '8766'
& $python .\app-sklad\server.py --no-browser
```

Откройте `http://127.0.0.1:8766/`. Сервер откроет скачанную базу app-sklad\sklad.db с перенесёнными заявками и справочниками. Первый запуск создаст новый вход и запишет пароль в %LOCALAPPDATA%\SkladVL\login.txt. Снимок от 18 ноября содержит 9 заявок, 1 фуру, 9 водителей, 173 контрагента и 416 банковских платежей. Вход выполните под `andrey` с паролем из этого файла. Команды запуска выполняйте в том же PowerShell или повторно задайте переменные в новом окне. Для остановки нажмите Ctrl+C в окне сервера.

Для запуска рабочего экземпляра на исходном компьютере есть `Запустить склад.bat`. Ярлык использует `python` из PATH. Команды выше явно указывают скачанную базу и личный файл входа. Для разработки создайте отдельную копию app-sklad\sklad.db и задайте SKLAD_DB путём к этой копии.

## Дополнительные возможности

Базовые сценарии открываются со стандартной библиотекой Python. Для выгрузки Excel и чтения таблиц установите `openpyxl` и `xlrd` в `.venv`. Для OCR фотографий и сканов и чтения PDF нужны библиотеки ниже. Выполните в отдельном окне PowerShell из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install openpyxl xlrd
.\.venv\Scripts\python.exe -m pip install rapidocr onnxruntime pymupdf Pillow numpy
```

Версии OCR-зависимостей в репозитории не закреплены. Первый запуск OCR может загрузить модели. Если его импорт падает, проверьте совместимость `RapidOCR`, `LangRec`, `ModelType` и `OCRVersion` с импортами в `app-sklad/raspoznat.py`. Для обычной работы с заявками OCR можно подключить позже.

## Проверка после запуска

1. Войдите и откройте вкладки «Заявки», «Фуры» и «Справочники».
2. Проверьте наличие перенесённых заявок, фуры, контрагентов и водителей. Эксперименты с созданием грузов проводите на отдельной копии базы.
3. Откройте сохранённую заявку и сформируйте имеющийся договор-заявку Word. Проверьте папку `Заявки из приложения`.
4. Проверьте предпросмотр ТН и экспедиторской расписки, смену участка и скачивание DOCX для ООО и ИП.

Если порт занят, смените `SKLAD_PORT` и адрес в браузере. Если пароль потерян, остановите тестовый сервер, проверьте, что `SKLAD_DB` и `SKLAD_CRED_FILE` указывают на тестовые файлы, выполните `& $python .\app-sklad\server.py --reset-password`, затем снова запустите сервер. Если видно предупреждение о резервировании, проверьте описание `backup.py` в [технической документации](ТЕХНИЧЕСКАЯ-ДОКУМЕНТАЦИЯ.md).

## Что переносится и что настраивается на новом компьютере

В main опубликованы база, все 57 вложений, 11 созданных Word-документов, шаблоны и факсимиле. Открывайте папку репозитория целиком. До установки дополнительных OCR- и Excel-библиотек доступны вход, просмотр данных и печать встроенных проектов документов.

Пароли почты задайте в настройке почты. Сетевой адрес, разрешения брандмауэра и абсолютные пути ярлыков зависят от компьютера. Начните с локального адреса 127.0.0.1. По умолчанию резервирование пытается писать в C:\РАБОТА\Резервные копии\Склад ВЛ. Если этот путь недоступен, приложение покажет предупреждение.

Перед обновлением репозитория сохраните текущую базу, вложения и созданные документы отдельной резервной копией. Git хранит опубликованный снимок данных. После начала работы база изменяется локально, и её нужно сохранять отдельно от обновлений кода.
