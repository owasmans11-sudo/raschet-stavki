# Итог сессии: картотека документов

**Дата:** 2026-10-24

1. **Задача:** одна таблица по всем документам, чтобы отвечать по ней, а не читать сотни PDF.
2. **Что сделали:** `tools/build_kartoteka.py` → `C:\РАБОТА\Картотека документов.xlsx` (+ kartoteka.json). Тип — раскладка другого чата
   (classes.json) и его правила, перенесённые в `tools/kart_*.py`; поля заявок — rows.json; новый разбор УПД/счетов/актов.
   Встроено в конец «Распознать сканы.bat».
3. **Результат:** 6396 документов: водители/машины 1675, заявки 1270, бухгалтерия 516, реквизиты 490, ТН 437, договоры 80 и др.
   «Комтранс» — 8 заявок с номерами, датами и суммами; «Щербинка» — 61 документ (в основном заявки перевозчикам).
4. **Что пошло не так:** номер счёта сначала брался из банковских реквизитов («№ 30101…») — теперь только рядом с названием документа
   или из имени файла; УПД путались со счёт-фактурой — имя файла решает; Excel не принимал управляющие символы из OCR.
5. **Правила на будущее:** чужие скрипты из scratchpad копировать в `tools/`, а не ссылаться на временные папки.
6. **Следующие шаги:** расписание Windows для автообновления (ждёт «да»), сверка заявок с УПД, карточка контрагента, «Архивариус».
