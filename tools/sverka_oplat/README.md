# Сверка заявок с оплатами по банковским выпискам (вариант 7, 2026-10-24)

Запуск по порядку из этой папки: `python parse.py` (выписки kl_to_1c_*.txt из C:\РАБОТА → ops.json),
`python load.py` (таблица варианта 6 → rows.json), `python match.py` (pays.json), затем `python build7.py`
(собирает «Заявки ВЛ и УПД — вариант 7.xlsx»). match2/match3 — промежуточные шаги, build7 их подключает.
Ручные разборы (Азимут S38/S39/538/539, АйМастер счета 39–41, Агама 254, ИКЛ П15, РусДилерТранс П41) — в build7.py.
Чтобы добавить выписку Альфа-Банка: положить kl_to_1c_…5142….txt в C:\РАБОТА и добавить р/с в match.py (VL/IP).
