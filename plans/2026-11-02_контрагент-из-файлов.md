# План: клиент / перевозчик из файлов

**Дата:** 2026-11-02  **Размер:** M  **Статус:** готов, обе фазы (2026-11-02)

## Что хотим получить
Как «водитель из файлов», только для компаний (слова владельца: «для клиентов тоже самое… чтобы данные брались или с заявки,
или с карточки предприятия»). Бросаешь карточку предприятия или заявку клиента (PDF, фото, Word, Ctrl+V) →
реквизиты заполнены → проверил → компания в справочнике и в заявке.

## Как будет работать
1. Вкладка **«Контрагенты»** (клиенты и перевозчики — один справочник): наименование, ИНН, КПП, ОГРН/ОГРНИП,
   юр. и почтовый адрес, р/с, банк, БИК, к/с, руководитель / подписант, основание полномочий, телефон, почта.
2. Окно **«Из файлов»** — как у водителей: перетащить / выбрать / Ctrl+V, картинки рядом, сомнительное — жёлтым.
3. Из **заявки клиента** берём реквизиты другой стороны: наши ИНН (ВЛ, ИП Шерстов, ТК МВЛ) отбрасываем.
   Если чужих компаний несколько (заказчик, грузоотправитель, получатель) — даю выбрать, какая нужна.
4. Проверки, чтобы не пропустить ошибку OCR: ИНН и ОГРН — по контрольной сумме, р/с вместе с БИК — по контрольному ключу.
5. В карточке груза поле **«Заказчик»** — подсказка из справочника + кнопка «из файлов»; в отрезках так же для **«Перевозчик»**.
6. **Печать:** заявка с клиентом — раздел 1 (наименование, ИНН/ОГРН/КПП, подписант, основание, контакты) и блок «16. Заказчик»
   полными реквизитами вместо пустых строк; заявка перевозчику — блок «11. Перевозчик».

## Фаза 2 (по желанию)
Из заявки клиента дополнительно предлагать данные груза: адреса погрузки/выгрузки, даты, груз, вес, ставку — с пометкой «проверить».

## Критерии приёмки
- [ ] Карточка предприятия (Word/PDF/фото) → реквизиты заполнены; ИНН, ОГРН, р/с проверены контрольными суммами.
- [ ] Заявка клиента с нашими и его реквизитами → взяты реквизиты клиента, не наши.
- [ ] Компания выбирается в грузе из подсказки; повторная загрузка дополняет её карточку, а не заводит вторую.
- [ ] Печать: в заявке с клиентом и заявке перевозчику реквизиты стороны заполнены.
- [ ] Прогон по архиву (525 карточек, 1283 заявки) — только счётчики найденных полей; проверка в браузере — на вымышленных документах.

## Не делаем
- Проверку по ФНС через интернет (можно добавить потом — по ИНН подтягивать официальное название и адрес).

## Риски
- В заявке несколько компаний — выбор вручную. Реквизиты в две колонки (наши | их) — OCR может перемешать строки.
