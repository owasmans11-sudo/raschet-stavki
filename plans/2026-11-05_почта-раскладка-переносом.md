# План: раскладывать почту ПЕРЕНОСОМ, без копий; в «Почте» остаётся только неопознанное

**Дата:** 2026-11-05  **Размер:** L  **Статус:** ждёт «да»

## Зачем
Владелец: «как мне контролировать новые сообщения, если их там тьма?». Сейчас в «Почте» лежит всё, а в «Перевозках» —
копии. Нужно: разобранное УХОДИТ из «Почты», мусор — в ПОМОЙКУ, в «Почте» остаётся только то, что программа не опознала
→ папка «Почта» = список «надо посмотреть».

## Как будет (только файлы из «Почты»; старый архив C:\РАБОТА не трогаем)
1. **Перевозка** `Перевозки\<Клиент>\<дата> Откуда–Куда, Фамилия\` — ПЕРЕНОСОМ:
   заявка с клиентом, заявка с перевозчиком, и относящиеся к ним счёт, акт, УПД, ТН.
2. **Счёт / акт / УПД → к перевозке**: по номеру заявки в документе («по договору-заявке № 164 от …»), водителю,
   номеру машины, маршруту и дате; контрагент счёта = перевозчик или клиент этой перевозки. Как у ТН: не уверены — не переносим.
3. **Документы водителя/машины** (ВУ, паспорт, СТС, ПТС, аренда, фото из того же письма) — переносом в `_Водители и машины\`.
4. **ПОМОЙКА**: тексты писем, логотипы и подписи, рассылки и уведомления (тип «Прочее»), нечитаемые фото без пары.
5. **Остаётся в «Почте»** (это и есть «на контроль»): заявки без пары, «похоже — проверь», счета/акты/ТН без перевозки,
   реквизиты, договоры, нераспознанное.
6. Поиск и картотека начинают смотреть в «Перевозки» (иначе перенесённое пропадёт из поиска и пар);
   программа помнит, какой файл куда перенесла, — пары не разваливаются при пересборке.
7. Отчёт остаётся: на каждом листе — где файл лежит сейчас; новое — жёлтым.

## Вопросы (с моей рекомендацией)
1. **Уже сделанные КОПИИ** в «Перевозках» (230 из старого архива за июнь–октябрь + ~130 из почты в `_Счета и акты`,
   `_Водители`, ТН) — рекомендую: копии из почты убрать (оригиналы перенесутся на их место), копии из старого архива
   удалить (оригиналы остаются в архиве). Тогда в «Перевозках» — только почта, разложенная переносом.
   Нужно твоё «да» на удаление копий.
2. **Счета/акты, которые к перевозке не привязались** — рекомендую оставить в «Почте» (на контроль), папку
   `_Счета и акты\<Контрагент>` больше не вести.
3. Ошибка программы = файл не там. Защита: всё перенесённое записывается в журнал (откуда → куда), есть команда
   «вернуть всё назад в Почту».

## Критерии приёмки
- [ ] После прогона в «Почте» нет текстов писем, логотипов, разложенных заявок/счетов/ТН/документов водителей.
- [ ] Ни одной копии: каждый файл лежит в одном месте; число файлов до = после (Почта + ПОМОЙКА + Перевозки).
- [ ] Повторный прогон ничего не двигает; новая почта вечером раскладывается так же.
- [ ] Поиск находит перенесённые файлы; пары после пересборки те же.
- [ ] Журнал переносов и команда отката проверены.

## Риски
- Программа ошиблась с парой → настоящий документ уехал не в ту папку. Поэтому переносим только «уверенное».
- Excel/файл открыт → перенос не получится; пропускаем, повторим вечером.
- Яндекс.Диск синхронизирует переносы — на других компьютерах файлы «переедут» тоже.
