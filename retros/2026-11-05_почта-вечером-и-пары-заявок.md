   заявку с клиентом и заявку с перевозчиком на одну перевозку класть вместе (папка по клиенту); неразобранное — в отчёт.

2. **Что сделали:** `mail-downloader/nightly_mail.py` (скачивание без окна), `mail-downloader/nightly_settings.py` +
   `Настройка почты.bat` (окно паролей), `tools/pary_zayavok.py` (пары + отчёт), исключение `C:\РАБОТА\Перевозки` из поиска

   Пары на старых заявках разложены: 66 перевозок → 78 папок, 230 копий в `C:\РАБОТА\Перевозки`, отчёт `Отчёт 2026-11-05.xlsx`.

4. **Что пошло не так и почему:** владелец прислал пароли приложений в чат — не использованы, попросил отозвать.
   Первая версия пар склеивала по одной паре «клиент–перевозчик» → дубли экземпляров и фуры с 2 клиентами; переделал на группы.
   Города по всему тексту врут (Иркутск в реквизитах ВЛ) — маршрут только из строк погрузки/выгрузки.
   Bash-heredoc и printf портят `\n` в путях Windows — файлы с обратными слэшами писать через Write/Edit.
5. **Правила на будущее:** пароли и ключи из чата не использовать; копии в `Перевозки` не индексировать.
6. **Следующий шаг:** владелец создаёт пароли приложений и вводит в «Настройка почты» → «Проверить вход» → «Скачать сейчас»;
