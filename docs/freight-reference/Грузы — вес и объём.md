## Расчёт по неполной карточке

1. Возьми известный размер и проверь лимит именно по этой стороне. Совпадение модели и упаковки позволяет добавить найденные в паспорте параметры. Для одинаковых коробок умножь внешний объём одной коробки на количество. Для перевозки на палетах используй внешние размеры собранных мест.
2. Для жидкости умножь фактические литры на плотность в кг/л. Прибавь массу тары и поддонов один раз. Если в карточке уже есть брутто, используй его.
3. Если известно «европалета» и число мест, но высота отсутствует, дай сценарии. Например, шесть палет без выступов занимают 5,76 м². При общей высоте каждого места 1,0 / 1,2 / 1,5 м объём составит 5,76 / 6,91 / 8,64 м³. Высоты в примере выбраны для сравнения, реальную высоту берём из заявки или спецификации.
4. По одному широкому названию и количеству мест можно дать предварительный сценарий, если есть сопоставимый артикул или тара. Покажи, что взято из паспорта, что предположено и какой диапазон цены даёт это предположение. При сопоставимых артикулах, дающих разные цены, сохрани диапазон для уточнения. Если известные данные дают одну итоговую цену во всех разумных сценариях, укажи её вместе с допущением.
5. Для решения по приёму груза сверяй согласованные пределы 6 т и 30 м³ на партию, 4 т и 4 × 2,45 × 2,50 м на место. Оценка массы партии по числу коробов не заменяет проверку массы самой тяжёлой палеты. Для партии с неизвестной упаковкой оставь оценку предварительной.
