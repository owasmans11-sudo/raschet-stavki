# План: почта каждый вечер + заявка с клиентом и с перевозчиком вместе

**Дата:** 2026-11-05  **Размер:** L  **Статус:** готов, кроме задачи в планировщике

## Что хотим получить
Каждый вечер сами скачиваются файлы с 2 почтовых ящиков. Заявка с клиентом и заявка с перевозчиком
на одну перевозку лежат вместе в одной папке. Всё неразобранное — в отчёте.

## Что уже есть (используем, не пишем заново)
- `mail-downloader/mail_core.py` — скачивание по IMAP: только новое, без дублей, текст писем, опись (`Опись.csv/html`).
  Сейчас умеет один ящик за раз и только из окна (`app.py`).
- `tools/nightly_update.py` + задача планировщика «ВЛ — обновление поиска и картотеки» (03:00):
  распознаёт новые сканы и фото, пересобирает картотеку. Только новые файлы.
- `tools/kart_roles.py` — отличает заявку с клиентом (`client`) от заявки ВЛ перевозчику (`carrier`).
- `tools/kart_fields.py` / картотека — номер, дата, маршрут, водитель, сумма у заявок.

## Риски и края
- Сканы: OCR коверкает слова, листы бывают перевёрнуты → при сомнении в отчёт, а не в пару.
- Одна заявка клиента — несколько перевозчиков (перегруз через склад, цепочка фуры) → одна папка, несколько заявок перевозчиков.
- Азимут и похожие: несколько заявок в один день с одной ставкой, отличаются только водителем — склеивать только по водителю.
- Заявка перевозчику, отправленная от нас, лежит в «Отправленных» — без неё пары не будет.
- Ноутбук выключен / нет интернета / пароль приложения отозван → ошибка в отчёте, задача не падает.
- Распознавание новых сканов ≈ 3–7 с на страницу — вечерний прогон может идти 10–30 минут.
