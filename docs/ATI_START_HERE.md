# Продолжение работы с ATI

Обновлено 18 ноября 2026 года. Основная задача — пройти всю подходящую выдачу ATI и сохранить внутренние комментарии «Андрей (сумма ₽)». Перед продолжением прочитать skills/ati-process-freight/SKILL.md и references/tariffs.md внутри этого навыка. Они содержат географию, ограничения и действующую формулу.

## Что находится в проекте

- skills/ati-process-freight — отбор и пакетный калькулятор, справочники грузов и расстояний.
- skills/vl-freight-reference — справочник массы и объёма, 1722 пары дорожных расстояний между Москвой и 41 городом МО, скрипт поиска пары.
- skills/vl-ati-queue — очередь по аккаунту и номеру карточки, проверка статуса комментария и продолжение после остановки.
- skills/vl-load-planning — проверка догрузов и загрузки рейса.
- skills/vl-incoming-documents — извлечение данных из входящих документов.
- skills/vl-trip-document-check — проверка комплекта документов рейса.
- skills/vl-payment-reconciliation — сверка оплат.
- docs/freight-reference — таблицы, источники и ограничения километража.

## Проверенный способ ускорения

Прочитать страницу выдачи целиком, собрать строки по номерам заявок, группировать одинаковые направления, брать пробег из справочника и считать цены пачкой через quote.py. При доступном управлении DOM сохранять комментарии в фоне, привязывая каждую запись к номеру заявки и аккаунту. Перечитать результат после сохранения. После неизвестного исхода перечитать карточку перед повторной записью.

По отчёту другого чата проба фоновой записи дала 7 сохранённых комментариев; последние 5 записаны и проверены за 18 секунд. Это скорость записи готовых цен. Полная обработка, включая чтение и проверку данных, в этом замере не измерялась.

## Точка продолжения

Пользователь остановил последний запуск 18 ноября. После остановки новые комментарии не вносились. Продолжать запись в ATI после нового поручения пользователя.

Прежние количества 211 и 246 отражают разные снимки меняющейся выдачи. Обновить список перед работой, сверить уже существующие комментарии. Отчёт другого чата содержал 57 рассчитанных цен из 246 уникальных объявлений, но цены в том проходе не записывались. Полный проход всех направлений ещё не подтверждён.

В этом чате подтверждались комментарии ZVE39612, IOP13164, OEH5011, MNS14373. В истории есть более ранние карточки и другие проходы. Этот список не является полной очередью; проверять текущие карточки и аккаунт.

При проверке продолжения 18 ноября отдельный CSV очереди в папке проекта не найден. Доступный браузер открыл ATI.SU и показал кнопку «войти». Проверка авторизации публичного API также потребовала входа. Статусы отдельных карточек в этом сеансе не перепроверялись.

После нового поручения открыть нужный аккаунт в браузере, обновить выдачу по всему коридору и восстановить CSV по паре «аккаунт + номер заявки», сверяя фактические комментарии. Перед повтором записи с неизвестным исходом сначала перечитать карточку.

## На новом устройстве

Скопировать папки skills в .codex/skills пользователя и открыть новый чат с этой папкой проекта. Навыки atisu-mcp и algo-sc-routing установлены из внешних источников, восстановить их по первоисточникам:
https://ati.su/developers/ai/
https://github.com/asgard-ai-platform/skills/tree/main/algo-sc-routing

Для ATI потребуется авторизация и доступный инструмент браузера. Подключение публичного API не даёт автоматически браузерную сессию. Проверять реально доступные возможности текущего сеанса.

Все записи о прогрессе — доступные рабочие сведения. Оригинальные чаты приложения восстанавливаются отдельно от файлов проекта.
