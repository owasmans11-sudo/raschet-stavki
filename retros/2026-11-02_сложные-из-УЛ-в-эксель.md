# 2026-11-02 — все сложные перевозки из «Умной логистики» в Excel

**Задача:** выгрузить все сложные перевозки из УЛ в Excel, как можно дешевле по лимиту.

**Как сделали:** Андрей сам сохранил «Отчёт по Сложным перевозкам» файлом `отчет.mxl` (формат 1С).
Я написал читалку этого формата (`tools/slozhnye_ul/mxl.py`) и сборщик (`tools/slozhnye_ul/build.py`) — без кликов по 1С.

**Результат:** `C:\РАБОТА\Сложные перевозки из УЛ.xlsx` — 42 сложные, 341 заявка, суммы по заявкам сходятся с итогами отчёта.

**Что узнали:** №3 в УЛ нет; адреса в отчёте — только города, вес/объём часто нули; у №44 нет ставки заказчику.

**Дальше:** при новой выгрузке — тот же запуск с новым .mxl.
