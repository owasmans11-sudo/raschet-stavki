# Справочники для расчёта перевозок ATI

Обновлено 18 ноября 2026 года.

В skills/ati-process-freight находятся правила отбора и калькулятор ВЛ. В skills/vl-freight-reference находятся справочник тары и товаров, поиск дорожного километража и матрица из 1722 направленных пар для Москвы и 41 города Московской области. Копии справочников и метаданные источника находятся в docs/freight-reference.

Для установки скопируйте обе папки из skills в папку .codex/skills своего пользователя. Откройте новый чат Codex. Запросите применение vl-freight-reference при расчёте заявок ATI.

Пример поиска:
python skills/vl-freight-reference/scripts/lookup.py Щелково Раменское

Расстояния рассчитаны OSRM между ориентировочными центрами городов в профиле driving. Ограничения грузовиков, актуальные пробки и точные адреса требуют отдельной проверки. На тарифных границах проверьте адресный пробег. Масса пустой тары и примерный вес товара задают сценарий, фактические данные заявки имеют приоритет.

Навык планирования маршрутов algo-sc-routing установлен локально из https://github.com/asgard-ai-platform/skills/tree/main/algo-sc-routing. Для нового устройства установите его из первоисточника.

CSV содержит исходный пробег без округления до тарифной ступени. Обратные направления хранятся отдельно. Суммы и коэффициенты берите из актуальных правил пользователя.
