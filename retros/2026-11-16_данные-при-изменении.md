# 2026-11-16 — данные при изменении

Проблема: форма изменения фуры показывала только краткие данные водителя, из-за чего паспорт и другие сохраненные сведения выглядели пропавшими. Также серверные обработчики могли обнулять поля, отсутствующие в частичном запросе.
Исправлено: в форме фуры редактируются предзаполненные поля существующего водителя; сохраняется тот же ID. Обработчики фуры, карточек, груза и этапов сохраняют отсутствующие поля. Прямое изменение поля применяется отдельно.
Проверено: частичные изменения не меняют соседние поля; сохранение без правок сохраняет карточку; правка паспорта меняет только паспорт в том же водителе; шаблон формы содержит прежние значения. Синтаксис JS/Python. После установки предыдущие строки фуры/водителя/контрагентов/груза сохранены, integrity_check/foreign_key_check без ошибок. HTTP 200 после перезапуска.
Резервная копия базы и исходников: outputs рабочего чата, папка «Склад ВЛ — сохранение данных при изменении 2026-11-16». Визуальный осмотр браузера не выполнен из-за системной политики Edge. Коммитов и публикаций нет.
