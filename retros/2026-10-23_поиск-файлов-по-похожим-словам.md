# Итог сессии: поиск файлов по похожим словам

**Дата:** 2026-10-23

1. **Задача:** Андрей хотел найти файлы по похожим словам (пример «Лукин А. В.»), чтобы программа предлагала варианты.
   Уточнил: нужен не скилл, а приложение с окном, которое берёт данные из проекта и показывает.
2. **Что сделали:**
   - движок `tools/find_files.py`: похожие слова (опечатки, падежи, латиница), инициалы, поиск в именах и внутри
     docx/xlsx/pdf с текстом/md/txt/csv; папки — проект и `C:\РАБОТА`; кеш текстов в `%LOCALAPPDATA%\vl_find_files`;
   - окно `tools/find_files_app.py`, запуск двойным щелчком по `Поиск файлов.bat` в корне проекта:
     строка поиска, кнопки «похожие слова», таблица с % похожести, открыть файл / показать в папке, кусок текста, где нашлось.
3. **Результат:** сделано. Проверено: «Лукин А. В.» по именам — 2 фото удостоверения Лукина (92%), Букин А.А. (80%), Губкин (62%).
   Поиск внутри файлов — первый проход собирает кеш (несколько минут).
