# Полная копия проекта на другом компьютере

Снимок подготовлен 18.11.2026 08:56.

Получите репозиторий командой git clone с веткой main. В копии есть исходники, рабочая база SQLite, вложения, созданные документы, факсимиле, планы, итоги и навыки.

Следуйте инструкции app-sklad/ЗАПУСК.md: она использует ветку main и скачанную базу, без создания пустой базы. Для открытия именно перенесённых данных задайте SKLAD_DB абсолютным путём к app-sklad/sklad.db внутри клона. Задайте SKLAD_CRED_FILE путём к новому личному файлу входа. Запустите python app-sklad/server.py --no-browser из корня клона и откройте адрес сервера.

В снимке сохранены бизнес-таблицы. Данные аутентификации и активные сеансы очищены, поэтому первый запуск выдаст новый пароль andrey. Сохраните его локально. Почтовые пароли задайте через настройку почты на новом компьютере. Локальные пути в сетевых настройках и ярлыках потребуется проверить для нового ПК.

Для резервного копирования после начала работы используйте механизм SQLite Backup приложения. Репозиторий содержит состояние данных на момент снимка. Новые изменения рабочей базы потребуют нового снимка.

В поставку не входят кэши Python, временные файлы Office, журналы браузерных тестов, окружения и личные наклейки tools/scooby_gifs.

Проверка загрузки выполнена 18 ноября 2026 года из свежего клона коммита 3f4bbad. Контрольная сумма базы совпала с отправленным снимком. integrity_check вернул ok. Сверены все 12 бизнес-таблиц, проверены новый вход и восемь разделов браузерного интерфейса. Скачивание 57 вложений и 11 созданных Word-документов прошло проверку, все 43 ссылки на вложения в справочниках найдены. Снимок содержит 9 заявок, 1 фуру, 6 складов, 8 менеджеров, 9 водителей, 173 контрагента и 416 платежей.

Проверка выполнена в отдельной папке на исходном Windows-компьютере с отключёнными внешними Python-пакетами. Для теста резервирования использовалась временная папка. Работа на физически другом компьютере, настройка сети, OCR и почтовая авторизация требуют отдельной проверки на целевом устройстве.
