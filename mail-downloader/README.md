# Вложения из почты

Маленькое приложение для компьютера: указываете даты «с … по …», нажимаете «Скачать»,
и оно сохраняет все файлы из входящих писем за эти дни в папку на компьютере
(можно разложить по месяцам или по отправителям), а рядом — текст каждого письма.
Письма не удаляются и не помечаются прочитанными.

## 1. Установить Python (один раз)

- **Windows:** скачайте с https://www.python.org/downloads/ и при установке
  поставьте галочку **«Add Python to PATH»**.
- **Mac:** скачайте установщик там же (в нём уже есть всё нужное для окна).

Больше ничего ставить не нужно, приложение использует только встроенные модули.

## 2. Подготовить Gmail (один раз)

Gmail не пускает сторонние программы по обычному паролю, нужен **пароль приложения**:

1. Включите двухэтапную аутентификацию: https://myaccount.google.com/security
2. Откройте https://myaccount.google.com/apppasswords, введите любое имя
   (например «Скачивалка») и нажмите «Создать».
3. Google покажет пароль из 16 букв, скопируйте его. Это и есть пароль для приложения.

IMAP в новых аккаунтах Gmail включён всегда. Если почта старая и подключиться не
получается, проверьте: Gmail → Настройки → «Пересылка и POP/IMAP» → «Включить IMAP».

## 3. Запустить

Положите `app.py` и `mail_core.py` в одну папку и запустите:

- **Windows:** двойной щелчок по `app.py` или в командной строке `python app.py`
- **Mac:** в Терминале `python3 app.py`

В окне укажите адрес почты и пароль приложения, даты «с» и «по» (ДД.ММ.ГГГГ, оба дня
включительно) и нажмите **Скачать**. Кнопки «Вчера», «Месяц», «Прошлый квартал»,
«Полгода», «Год» только заполняют даты — их можно поправить руками.

Файлы сохраняются в `Загрузки/Вложения из почты` (папку можно поменять кнопкой «…»).
К имени каждого файла добавляется дата письма, например `2026-10-05_Счёт.pdf`;
одинаковые имена не перезаписываются, а получают номер `(1)`, `(2)`.
Повторный запуск уже скачанное не дублирует.

## Раскладка, текст писем и опись

- **Раскладка:** «По месяцам» (`2026-09\`), «По отправителю» (папка по адресу, `info@firma.ru\`),
  «Месяц → отправитель» (`2026-09\info@firma.ru\`) или «Одной папкой».
- **Текст писем** (галочка): на каждое письмо, даже без вложений (например, отмена заявки),
  рядом с файлами кладётся `2026-09-14 10-32_ПИСЬМО_Тема.txt` — ящик, от кого, кому, дата,
  тема, список вложений, ссылка на письмо и сам текст.
- **Опись:** в корне папки `Опись.html` (кнопка «Открыть опись»: поиск по имени файла,
  отправителю, теме; ссылки на файл, текст письма и письмо в почте) и `Опись.csv` для Excel.
  Видно, с какого ящика и из какого письма скачан каждый файл.
- **Ссылка «в почте»:** у Gmail — точная ссылка на письмо. Mail.ru и Яндекс точных ссылок
  программам не дают, поэтому там ссылка на поиск в почте по теме письма.

Если отметить «Запомнить пароль», настройки и пароль сохраняются в файле
`.mail_downloader.json` в домашней папке, чтобы не вводить их каждый раз.
Пароль приложения можно в любой момент отозвать на странице из шага 2.
