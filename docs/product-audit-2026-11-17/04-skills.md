## Как передать эту возможность команде

1. Открыть продукт самостоятельным проектом Codex. Для первой предметной задачи выбрать T02 из [плана](03-roadmap.md). В запросе указать конкретный навык для диагностики или проверки и ожидаемый наблюдаемый результат.
2. Перед публикацией выбранных пакетов проверить входящие скрипты, ссылки, необходимые инструменты и условия распространения. Затем отдельным коммитом добавить нужные навыки в `raschet-stavki/.agents/skills`. Копировать пользовательские настройки или ключи доступа для этого не требуется.
3. На чистом клоне проверить список навыков из корня проекта. Затем выполнить одну полезную пробу: создать синтетический тест разделения оплаченного груза, запустить и сохранить результат. Обнаружение навыка и выполнение задачи — отдельные критерии приёмки.
4. В `AGENTS.md` целесообразно хранить стабильные команды запуска, проверки и расположение эталонных данных. Отдельные навыки оставлять для процедур с несколькими шагами. При обновлении навыка менять проектную копию и проверять, не расходится ли она с таким же личным пакетом.

Рабочие оригиналы, пароли и коммерческие документы для проверки навыков не использовались. Сами проектные навыки не редактировались и не отправлялись в GitHub.
