# План: водитель из файлов — «в моменте»

**Дата:** 2026-11-02  **Размер:** M  **Статус:** готов (2026-11-02)

## Что хотим получить
Много новых водителей, данные нужны сразу при оформлении (слова владельца: «зачастую надо в моменте»).
Водитель прислал фото паспорта / прав / СТС (WhatsApp, почта, Word) → бросаешь файлы в приложение или вставляешь Ctrl+V →
через несколько секунд поля заполнены → проверил → водитель в заявке и в справочнике.

## Как будет работать
1. В карточке груза (отрезки «забор», «развоз») и в окне фуры — кнопка **«Водитель из файлов»**.
   Можно: перетащить файлы, выбрать на диске или вставить картинку из буфера (Ctrl+V — например, скопированную в WhatsApp).
   Сразу несколько файлов: паспорт + права + СТС тягача + СТС прицепа.
2. Распознавание — тот же движок, что в «Распознать сканы» (RapidOCR, кириллица); держим его загруженным, чтобы не ждать.
   Понимает: jpg/png/jfif/heic(если откроется)/pdf/docx.
3. Разбор полей:
   - паспорт — ФИО, серия и номер, кем и когда выдан, код подразделения, дата рождения;
   - права — номер, дата выдачи, категории;
   - СТС — госномер, марка/модель, номер СТС (тягач и прицеп отдельно);
   - телефон; перевозчик (ИП/ООО, ИНН), если есть в карточке водителя.
4. Окно проверки: найденные поля + картинка документа рядом. Сомнительное — жёлтым
   (неполный номер, госномер не по шаблону, дата не похожа на дату). Правишь → «Сохранить».
5. Водитель попадает в **справочник «Водители»** (поиск по ФИО, госномеру, телефону) и подставляется в отрезок/фуру.
   В следующий раз — просто выбрать из подсказки в поле «Водитель».
6. **Печать заявки перевозчику** заполняет разделы 8 «Данные на машину» и 9 «Данные на водителя» целиком.

## Критерии приёмки
- [ ] Фото паспорта + прав + СТС → поля заполнены, на всё ≤ 15 с.
- [ ] Ctrl+V картинки из буфера работает.
- [ ] Сохранённый водитель выбирается в другой заявке из подсказки.
- [ ] Печатная заявка перевозчику — разделы 8 и 9 заполнены.
- [ ] Прогон разбора по архиву (2175 распознанных документов водителей): считаю, у скольких нашлись поля — только цифры,
      без личных данных в чате; 5–10 документов сверяю глазами.

## Не делаем
- Не тянем файлы из WhatsApp сами (нет доступа) — файл сохраняешь или копируешь картинку.
- Не проверяем паспорт по базам МВД.
- Массовую загрузку водителей из архива — потом, отдельно, если захочешь.

## Риски
- Фото под углом/блики — номер может не прочитаться → поле жёлтое, ввод руками.
- Номер паспорта напечатан вертикально — разворачиваем картинку и пробуем ещё раз.
- Серия-номер паспорта и номер прав одинакового вида (10 цифр) — различаем по типу документа.
