# План: расшифровка звонков продажников → карточка для логиста

**Дата:** 2026-10-29  **Размер:** M  **Статус:** черновик

## Что хотим получить
Владелец: «следить за звонками … и выписывать текстом звонки», чтобы «передать от продажника к логисту правильную информацию».
Пилот — один продажник, Android, запись на самом телефоне.

## Критерии приёмки
- [ ] Продажник поговорил с клиентом → запись сама появилась на этом компьютере (без кабеля, без ручной пересылки).
- [ ] Запись появилась → через несколько минут рядом лежит текст разговора.
- [ ] Из текста сделана карточка для логиста: откуда, куда, груз, вес, объём, упаковка, даты погрузки, ставка, НДС,
      форма оплаты, особые условия, что пообещали клиенту. Чего не было в разговоре — «не обсуждали — уточнить».
- [ ] Проверено на 3–5 настоящих звонках; владелец сказал, что карточки годятся.

## Не делаем
- Не слушаем звонки в прямом эфире.
- Не подключаем виртуальную АТС и запись у оператора (это потом, если пилот понравится).
- Не отправляем записи ни в какие сторонние сервисы расшифровки: расшифровка только на этом компьютере.

## Фазы
### Фаза 1: телефон продажника
- Включить автозапись всех звонков во встроенной «звонилке» (как именно — зависит от марки телефона).
- Поставить приложение синхронизации папки (например, FolderSync) → папка записей уходит на Яндекс Диск сама.
- Как проверим: тестовый звонок → файл появился на Яндекс Диске.
- Статус: [ ]

### Фаза 2: компьютер — приём и расшифровка
- Яндекс Диск на компьютере синхронизирует папку «Звонки» (проверить, установлен ли).
- Поставить программу расшифровки faster-whisper (работает без интернета, на процессоре).
- Скрипт `tools/zvonki.py`: следит за папкой, новые записи → текст `.txt` рядом.
- Как проверим: тестовая запись → текст, сверить на слух.
- Статус: [ ]

### Фаза 3: карточка для логиста
- Текст → карточка (Claude по готовому шаблону полей), складывается в папку логиста / строкой в таблицу.
- Как проверим: 3–5 настоящих звонков, владелец смотрит карточки.
- Статус: [ ]

## Риски и края
- Компьютер: Ryzen 5 5500U, 15 ГБ памяти, без видеокарты — расшифровка 5-минутного звонка займёт несколько минут. Для пилота хватит.
- Python 3.14 — у программы расшифровки может не быть готовой сборки под него; тогда поставить отдельный Python 3.12 рядом.
- Встроенная запись звонков есть не у всех марок; на телефонах с «звонилкой» Google собеседник слышит «звонок записывается».
- Сторонние приложения-диктофоны на новых Android часто пишут только голос продажника — их не используем.
- Записи — личные данные (голоса, номера): хранить только на рабочем компьютере, в git не класть.
- Продажника предупредить письменно; клиентам лучше говорить «разговор записывается».
- Карточка — только как подсказка: цифры (ставка, вес) логист сверяет с продажником, пока не убедимся в точности.
