# Итог сессии: печать заявок ВЛ из приложения «Склад»

**Дата:** 2026-11-02

1. **Задача:** кнопки печати заявок в фирменном стиле ВЛ прямо из приложения.
2. **Что сделали:** `app-sklad/pechat.py` — собирает Word-заявку в стиле «вариант 3» (`tools/vl_style.py`);
   юридический текст и наши реквизиты читаются из утверждённых шаблонов «новый дизайн» в корне (шаблоны не менялись).
   Кнопки: в карточке груза — «с клиентом», «перевозчику — забор», «перевозчику — развоз» (сначала сохраняют карточку);
   в окне фуры — «Печать заявки на фуру». Файлы — `Заявки из приложения/` (в .gitignore), сразу открываются в Word;
   если файл открыт в Word — сохраняется рядом с «(2)». Шаблон выбирается по компании груза; нет шаблона — понятная ошибка.
3. **Результат:** решено — проверено: 5 заявок из примера С534НХ03 → Word → PDF (3–4 стр.), смотрел глазами первую и последнюю
   страницы; сверка с шаблонами — условий 22/22 (перевозчик) и 49/49 (клиент), реквизитов — 0 расхождений.
   Кнопки в приложении работают (печать через API без открытия Word), ошибка для ИП на заборе выводится.
4. **Что пошло не так и почему:** вес печатался «17 51 кг» (обрезались нули у целых) и город склада повторялся
   («Щербинка, Щербинка, …») — исправлено до показа владельцу.
5. **Правила на будущее:** заявки заполнять только из утверждённых шаблонов, юр. текст не трогать (как и раньше).
6. **Следующий шаг:** владелец смотрит 4 примера в `Заявки из приложения/`. Нет шаблонов: забор от ИП Шерстов, заявка с клиентом
   от ИП Шерстов — спросить, нужны ли. Дальше по фазе 2: справочники (реквизиты перевозчиков/клиентов подставлять в заявку).
