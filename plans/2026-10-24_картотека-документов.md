# План: картотека документов

**Дата:** 2026-10-24  **Размер:** M  **Статус:** готов

## Что хотим получить
Одна таблица по всем документам (заявки, УПД, счета, акты, ТН, договоры, документы водителей): тип, номер, дата, заказчик/перевозчик,
маршрут, водитель, сумма, файл. Чтобы отвечать по таблице, а не читать сотни PDF. Потом на ней — сверка заявок с УПД и «Архивариус».

## Критерии приёмки
- [ ] `C:\РАБОТА\Картотека документов.xlsx` — лист «Все документы» (≈6400 строк: PDF, Word, Excel, фото) со ссылкой на файл.
- [ ] У заявок заполнены номер / дата / сумма / заказчик / водитель / погрузка там, где их нашёл другой чат (rows.json, ≈880 заявок, с его ручными поправками).
- [ ] У УПД, счетов и актов — номер, дата, сумма, продавец/покупатель (новый разбор текста), где читается.
- [ ] Сомнительные значения помечены «проверить», а не выдуманы. Пусто — значит не нашлось.
- [ ] Копия для программ: `%LOCALAPPDATA%\vl_find_files\kartoteka.json`. Пересборка одной командой, ≈минуты, без OCR заново.
- [ ] Проверка на примерах: заявки Щербинки, «Комтранс», Лукин — строки есть и поля похожи на правду (сверю с 5–10 файлами глазами).

- Повторное распознавание и исправление самих файлов.
