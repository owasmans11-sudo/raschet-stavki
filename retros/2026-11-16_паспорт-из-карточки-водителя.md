# 2026-11-16 — паспорт из карточки водителя

Задача: при загрузке Word-карточки водителя не подставлялся номер паспорта.
Причина: PASSPORT_NUM не допускал знак № между серией и номером.
Изменено: app-sklad/raspoznat.py — знак № необязателен, поддержаны повторные и неразрывные пробелы. Старый файл сохранён в outputs рабочего чата.
Проверено: 6 вариантов номера, 3 отрицательных случая, полный from_files на присланном DOCX без вывода персональных значений; установленный файл совпал с проверенным. Сервер перезапущен, главная страница HTTP 200.
Существующие карточки не перезаписывались. Для незаполненной карточки требуется повторить импорт файла. Коммитов и публикаций нет.
