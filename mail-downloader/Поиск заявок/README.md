# Поиск заявок

Приложение просматривает все файлы в папке с вложениями из почты (PDF, Word,
Excel, картинки и сканы, архивы zip/rar/7z), находит **заявки на перевозку, где
перевозчик — «Восточная логистика»**, копирует их в отдельную папку и делает отчёт в Excel.

## Как пользоваться

1. Запустите `Запустить.bat` (или `python app.py`).
2. «Где искать» — папка с вложениями (по умолчанию `Загрузки\Вложения из почты`).
   «Куда сложить» — куда положить найденное (по умолчанию `Загрузки\Найденные заявки`).
3. Нажмите **Найти заявки**. Первый проход по 10 тысячам файлов может занять
   час-другой из-за распознавания сканов; повторные запуски быстрые, потому что
   прочитанный текст запоминается (`~\.zayavki\cache.sqlite`).

## Что получается

- `Заявки` — заявки на перевозку, где наша компания указана перевозчиком.
- `Проверить вручную` — похоже на заявку, но роль компании не ясна или скан плохо читается.
- `Мы заказчик` — заявки, где «Восточная логистика» заказчик (мы нанимаем другого перевозчика).
- `Отчёт ….xlsx` — все файлы с итогом, баллом, найденными признаками и началом текста.
  Есть фильтр по столбцам; имя файла в отчёте — ссылка на него.

Файлы из архивов копируются по отдельности, с именем архива в начале.
Одинаковые файлы (пришли из нескольких почт) отмечаются как «Дубликат» и не копируются дважды.

## Установка (один раз)

```
python -m pip install -r requirements.txt
```

Для картинок и сканов нужен Tesseract OCR с русским языком:
`winget install UB-Mannheim.TesseractOCR`, затем файл
https://github.com/tesseract-ocr/tessdata_fast/raw/main/rus.traineddata (и eng.traineddata)
положить в `%USERPROFILE%\.zayavki\tessdata`. Без Tesseract картинки просто пропускаются.
Для архивов .rar нужен установленный 7-Zip или WinRAR.

## Как решается, что это заявка

Ищутся признаки заявки на перевозку («договор-заявка», «заявка на перевозку»,
перевозчик, грузоотправитель, погрузка, водитель, госномер, маршрут, ставка…), и
смотрится, какое слово стоит перед названием нашей компании: «Перевозчик/Исполнитель»
или «Заказчик/Экспедитор». Счета, акты, УПД и накладные отбрасываются.
В поле «Наша компания» можно добавить через запятую другие варианты названия или ИНН.
