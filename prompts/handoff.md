# Передача работы в новый чат

**Для чего:** когда чат разросся или задача поменялась, сохранить состояние в файл и продолжить с чистого листа без потерь.
**Кому:** все.
**Что подставить:** `{{задача}}` — короткое название.

## Текст (сказать в старом чате)

```
Подготовь передачу в новый чат. Сначала запиши файл `progress/{{задача}}-handoff.md`, потом покажи его мне.

Структура файла:
1. Цель — одним предложением.
2. Что сделано — по пунктам, с путями к файлам.
3. Где остановились и какой следующий шаг — конкретно.
4. Принятые решения и почему.
5. Чего делать НЕ надо — что пробовали и отвергли, и по какой причине.
6. Как проверить результат — команда или действие и что должно получиться.
7. Открытые вопросы ко мне.

Не включай ключи, пароли и персональные данные — только ссылки на файлы, где они лежат.
Только факты из работы; если что-то не знаешь, пиши «неизвестно».
```

## Текст (первое сообщение в новом чате)

```
Продолжаем работу. Прочитай `progress/{{задача}}-handoff.md` и повтори своими словами: цель, где остановились,
следующий шаг. Не начинай делать, пока я не подтвержу, что ты понял верно.
```

## Пример результата

Файл с блоком «Чего делать не надо»: «не использовать библиотеку X — несовместима с нашей версией Y».
