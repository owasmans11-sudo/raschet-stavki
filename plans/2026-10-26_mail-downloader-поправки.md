## Что хотим получить
Свои даты «с … по …»; раскладка по месяцам или по отправителю; текст письма рядом с вложениями;
у каждого файла видно, с какой почты и из какого письма он скачан, по возможности — ссылка на письмо.

## Критерии приёмки
- [ ] В окне поля «С» и «По» (ДД.ММ.ГГГГ) + быстрые кнопки: Вчера, Месяц, Квартал (прошлый), Полгода, Год.
      Скачиваются письма ровно за эти дни, включая оба края.
- [ ] Выбор раскладки: «По месяцам» (`2026-09\`), «По отправителю» (`info@firma.ru\`),
      «Месяц → отправитель», «Одной папкой» (как сейчас).
- [ ] Галочка «Сохранять текст писем» (вкл. по умолчанию): на КАЖДОЕ письмо, даже без вложений (отмены!),
      файл `2026-09-14 10-32_ПИСЬМО_Тема.txt`: ящик, от кого, кому, дата, тема, список вложений, ссылка, текст.
- [ ] `Опись.csv` (для Excel) и `Опись.html` (открыть в браузере, Ctrl+F по имени файла) в корне папки:
      файл → ящик, от кого, тема, дата, кликабельные ссылки «файл», «текст письма», «письмо в почте».
- [ ] Ссылка «письмо в почте»: Gmail — точная ссылка на письмо; Mail.ru и Яндекс — ссылка на поиск по теме письма
      (точной ссылки эти почты программам не дают). Текст письма на диске — ссылка всегда.
- [ ] Повторный запуск не плодит дубли ни файлов, ни строк описи.
