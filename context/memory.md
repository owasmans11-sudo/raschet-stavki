# Память проекта

Сюда агент записывает то, что узнал в диалогах. Читается в начале каждого диалога.
Старое не удалять — если факт устарел, пометить «устарело (дата)» и записать новый.
Личные данные людей (телефоны, почты, паспорта) сюда не писать.

  (слова владельца, 2026-10-17).
- Онбординг не завершён: шаг 1 «Знакомство» готов (2026-10-23), дальше шаг 2 (`context/progress.md`).

  через `msiexec /a` (распаковка) поверх той же папки — tkinter 9.0 работает. Файлы .py привязаны к python.exe в HKCU\Software\Classes.
  mail-downloader запускать: `pythonw app.py` из папки `mail-downloader` (или двойной щелчок по app.py). Node нет. Без Python текст можно достать так: Word COM (PDF/DOC/DOCX), Excel COM (XLS/XLSX). Для PDF в Word на время ставить
  `HKCU\...\Word\Options\DisableConvertPdfWarning=1` и потом удалять. Скрипт: `Downloads\ВЛ_totext.ps1`.
