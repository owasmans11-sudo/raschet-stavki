# 2026-11-16 — доступ по локальной сети

Пользователь явно разрешил предоставить приложению доступ в локальной сети. Определен Wi-Fi IP 192.168.0.105/24; VPN отдельно. В server.py добавлены network.json, прием на интерфейсах и проверка источника: localhost и только 192.168.0.0/24; остальные адреса отклоняются. Аутентификация не менялась.
Создано узкое правило Firewall SkladVL-Local-WiFi-8765 (программа Python приложения, Wi-Fi, localIP192.168.0.105, TCP8765, remote192.168.0.0/24). Сетевой профиль Public сохранен. Потребовалось административное подтверждение Windows; правило затем прочитано и сверено.
Проверки: peer-фильтр localhost/LAN/VPN/public, страница входа HTTP200 через оба адреса, /api/state без входа401, фактические параметры правила. Другой компьютер проверить недоступно, ограничение указано в инструкции. Опубликован только локальный адрес, проброса порта/интернет-публикации не было. Основной компьютер должен быть включен; IP зависит от DHCP. Личные учетные записи и роли не добавлялись, база общая.
Инструкция и .url-ярлык, исходник до/после, network.json и проверенные параметры Firewall сохранены в «Работа с Codex», оба журнала дополнены.
