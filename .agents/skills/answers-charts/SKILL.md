---
name: answers-charts
description: Build readable charts of sales, costs, profit and other business metrics from supplied data.
---
Confirm the metric, units, date range, aggregation and comparison from the request. Read the actual data, distinguish missing values from zeros, and reconcile totals against the source. Compute margins as ratios of aggregated amounts. Use a line for a time series, horizontal bars for ranked categories and a scatter plot for relationships. Label units, currency and periods, start bar axes at zero, and distinguish estimates. Use the available spreadsheet tools for an editable workbook or a plotting library for a standalone image. Render and inspect the result for clipping and verify plotted values against the source. Return the chart and the observation that answers the user’s question.
