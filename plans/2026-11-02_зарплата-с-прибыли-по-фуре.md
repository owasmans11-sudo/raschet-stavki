# План: расчёт зарплаты с прибыли по фуре

**Дата:** 2026-11-02  **Размер:** M  **Статус:** в работе (поправки Андрея 2026-11-02 учтены)

## Что хотим получить
Excel-файл, где по каждой фуре видно: выручку по заявкам, налоги, все расходы, остаток прибыли по каждой заявке,
прибыль на 1 кг и % прибыли от выручки — и зарплату сотрудников, которая начисляется только после оплаты клиента.

## Как считаем (допущения — поправь, если не так)
1. **Заявка клиента:** выручка, компания (ООО ВЛ / ИП Шерстов / МВЛ), форма оплаты: с НДС 1,22 / без НДС (УСН) 1,06 / нал 1.
2. **Налог с выручки** = Выручка − Выручка / Кф (как в общей таблице логистов).
3. **Свои расходы заявки:** водитель до склада, водитель развоза, прочие (СДЭК, кран) — у каждого своя форма оплаты.
   Если клиент платит с НДС, НДС перевозчиков с 1,22 возвращается в плюс; при 1,06 и наличных — нет (твоё правило от 28.10).
4. **Общие расходы фуры:** фура склад→склад + склад погрузки + склад приёмки (+ общие прочие) → делятся между заявками **по кг**:
   стоимость 1 кг = общие расходы / общий вес фуры; доля заявки = её кг × стоимость 1 кг.
5. **Остаток прибыли заявки** = Выручка − Налог − Свои расходы − Доля общих расходов.
   Рядом: **прибыль на 1 кг** = Остаток / кг заявки, **% от выручки** = Остаток / Выручка.
6. **Зарплата** = Остаток × 20% логисту заявки (Александр, Артём, Таня, Ильяс, Оля, Андрей, Илья) — **только когда клиент оплатил полностью** (статус «оплачено» + дата).
   Пока не оплачено — сумма в колонке «ждёт оплаты». Если остаток в минусе — зп 0, минус виден отдельно.
7. **Налог на прибыль 25%** вычитаем у компаний на ОСНО (ООО ВЛ) с прибыли заявки, если она в плюсе (Андрей 2026-11-02). У ИП на УСН 6% — не вычитаем (УСН его заменяет).

## Устройство файла
- Лист «Фуры» — одна строка на фуру: номер ТС, дата, маршрут, ставка фуры, склады, общие прочие, итог кг, стоимость 1 кг.
- Лист «Заявки» — одна строка на заявку: фура (выбор из списка), клиент, логист, компания, форма оплаты, выручка, кг, м³,
  свои расходы, оплата (сумма, дата) → налог, доля общих расходов, остаток, ₽/кг, % от выручки, зп.
- Лист «Зарплата» — по сотрудникам и месяцам (по дате оплаты): начислено, ждёт оплаты.
- Лист «Настройки» — коэффициенты (1,22 / 1,06 / 1), % зп (20%), список сотрудников и компаний.

## Критерии приёмки
- [ ] Ввёл фуру и 3 заявки с разными формами оплаты → остаток, ₽/кг, % и зп считаются формулами без ошибок.
- [ ] Заявка без оплаты → зп в «ждёт оплаты», в начисленное не попадает; поставил оплату → перешла в начисленное.
- [ ] Сумма долей общих расходов по фуре = общим расходам фуры.
