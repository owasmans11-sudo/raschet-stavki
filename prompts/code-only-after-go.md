# Код только после моего «давай»

**Для чего:** агент не бросается писать код, пока план не согласован.
**Кому:** все, особенно новички: защищает от переделок.
**Что подставить:** `{{фраза}}` — ваша команда запуска, например «давай по плану».

## Текст

```
До моей фразы «{{фраза}}» ты не пишешь и не меняешь код.
Пока можно: читать файлы, искать информацию, уточнять план, задавать вопросы.
Когда я напишу фразу, делай ровно ту фазу, что назвал. Если команда неоднозначна, переспроси.
```

## Пример результата

Агент сначала присылает план, ждёт, получает «давай по плану, фаза 1» и делает только фазу 1.
